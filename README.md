# 🧬 NEUROGEN - AI Drug Discovery Platform

An AI-powered drug discovery platform that generates novel molecular structures using diffusion models.

## 🌐 Live Demo
👉 [https://nikhitha9-neurogen.hf.space](https://nikhitha9-neurogen.hf.space)

## 🚀 Features
- 🔬 Input SMILES notation to generate new drug candidates
- 🖼️ 2D molecular visualization
- 🔭 3D interactive molecular viewer
- 🧪 AI diffusion model for molecule generation
- 📊 Generation history tracking

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **AI Model:** PyTorch Diffusion Model
- **Chemistry:** RDKit
- **Frontend:** HTML, Tailwind CSS, 3Dmol.js
- **Deployment:** Hugging Face Spaces (Docker)

## 📦 Installation
```bash
git clone https://github.com/NIKHITHA-99/Neurogen
cd Neurogen
pip install -r requirements.txt
python app.py
```

## 💡 How to Use
1. Enter a SMILES string (e.g. `C1=CC=CC=C1` for Benzene)
2. Click **Generate Molecular Structure**
3. View 2D and 3D molecular structures
4. Explore generation history
